# ドキュメント更新

## 概要

関連ドキュメントを更新する。
次の手順に従って作業を進め、不明点があればユーザーへ質問する。
作業後にチェックリストを参照し、すべての項目が完了していることを確認する。

## 手順

### 1. 実装状況を確認
- 直近の変更内容を確認する
- 変更された機能や追加された機能を把握する

```bash
git fetch origin
git checkout <branch-name>
git diff origin/develop...HEAD
```

### 2. ドキュメントとの差分を確認
- `/docs` 内のドキュメントと実装の差分をチェックする

### 3. ドキュメントを更新
- 実装と一致するようにドキュメントを修正する
- 追加された機能の説明を記載する

## チェックリスト

### 作業完了確認
- [ ] 直近の変更内容を確認した
- [ ] ドキュメントと実装の差分を確認した
- [ ] 差分がある箇所をすべて更新した
- [ ] 追加された機能の説明を記載した

### 品質確認
- [ ] 実装と一致している
- [ ] 用語・表記が統一されている
- [ ] typoがない
- [ ] 日本語で記載されている
