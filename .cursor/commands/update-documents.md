# ドキュメント更新

## 概要

関連ドキュメントを更新します。

次の手順に従って作業を進め、不明点があればユーザーへ質問する。
作業後にチェックリストを参照し、すべての項目が完了していることを確認する。

## 用途

開発の最新バージョンに合わせて、関連するドキュメントを更新する際に使用します。

## 手順

### 1. 実装状況を確認
- 直近の変更内容を確認する
- 変更された機能や追加された機能を把握する

```bash
# 直近のコミットからの差分を確認
git diff HEAD~5..HEAD

# 特定のブランチとの差分を確認
git diff main...HEAD
```

### 2. ドキュメントとの差分を確認
- `/docs` 内のドキュメントと実装の差分をチェックする
  - システム概要が最新か
  - 機能一覧が最新か
  - セットアップ手順が正確か
  - APIエンドポイントが最新か
  - 環境変数が最新か
  - アーキテクチャ図が最新か

### 3. ドキュメントを更新
- 差分がある箇所を更新する
- 実装と一致するようにドキュメントを修正する
- 追加された機能の説明を記載する

## チェックリスト

### 作業完了確認
- [ ] 直近の変更内容を確認した
- [ ] ドキュメントと実装の差分を確認した
- [ ] 差分がある箇所をすべて更新した
- [ ] 追加された機能の説明を記載した

### 品質確認
- [ ] 実装と一致している
- [ ] コード例が実行可能
- [ ] 用語・表記が統一されている
- [ ] typoがない
- [ ] 日本語で記載されている
- [ ] センシティブ情報が含まれていない
