# テスト作成

## 概要

ユニットテストコードを生成します。

次の手順に従って作業を進め、不明点があればユーザーへ質問する。
作業後にチェックリストを参照し、すべての項目が完了していることを確認する。

## 用途

指定したコードに対するユニットテストのコードを自動で作成したい場合に使用します。

## 手順

### 1. テスト対象を確認
- テスト対象のファイル・クラス・関数を特定する
- テストの種類を決定する
  - **ユニットテスト**: `tests/unit/` - 個別のクラスや関数
  - **統合テスト**: `tests/integration/` - データベースやインフラとの統合
  - **コントラクトテスト**: `tests/contract/` - APIエンドポイント

### 2. テストケースを設計
- 正常系のテストケースをリストアップする
- 異常系のテストケースをリストアップする
- 境界値のテストケースをリストアップする

### 3. テストを実装
- AAAパターンに従ってテストを記述する
- テスト名を日本語で命名する（`test_OK_xxx`, `test_NG_xxx`）
- docstringを日本語で記載する

### 4. テストを実行

```bash
# すべてのテスト（カバレッジ付き）
uv run --frozen pytest -v --tb=short --cov=src --cov-report=term

# 特定のディレクトリ
uv run pytest tests/unit/domain/user/

# HTMLカバレッジレポート生成
uv run pytest --cov=src --cov-report=html tests/
open htmlcov/index.html
```

## チェックリスト

### テスト内容
- [ ] 正常系のテストがある
- [ ] 異常系のテストがある
- [ ] 境界値のテストがある

### コード品質
- [ ] テスト名が適切（日本語: `test_OK_xxx`, `test_NG_xxx`）
- [ ] docstringが記載されている（日本語）
- [ ] AAAパターンに従っている
- [ ] モックが適切に使用されている

### 実行結果
- [ ] すべてのテストがパス
- [ ] カバレッジが十分（目安: 85%以上）
