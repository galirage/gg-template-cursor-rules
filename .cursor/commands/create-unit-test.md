# 単体テスト作成

## 概要

単体テストコードを生成する。
次の手順に従って作業を進め、不明点があればユーザーへ質問する。
作業後にチェックリストを参照し、すべての項目が完了していることを確認する。

## 手順

### 1. テスト対象を確認
- テスト対象のファイル・クラス・関数を特定する

### 2. テストケースを設計
- 正常系のテストケースをリストアップする
- 異常系のテストケースをリストアップする
- 境界値のテストケースをリストアップする

### 3. テストを実装
- AAAパターンに従ってテストを記述する
- テスト名を日本語で命名する（`test_OK_xxx`, `test_NG_xxx`）
- docstringを日本語で記載する

### 4. テストを実行

```bash
# すべてのテスト（カバレッジ付き）
uv run --frozen pytest -v --tb=short --cov=src --cov-report=term
```

## チェックリスト

### テスト内容
- [ ] 正常系のテストがある
- [ ] 異常系のテストがある
- [ ] 境界値のテストがある

### コード品質
- [ ] テスト名が適切（日本語: `test_OK_xxx`, `test_NG_xxx`）
- [ ] docstringが記載されている（日本語）
- [ ] AAAパターンに従っている
- [ ] モックが適切に使用されている

### 実行結果
- [ ] すべてのテストがパス
- [ ] カバレッジが十分（目安: 85%以上）
