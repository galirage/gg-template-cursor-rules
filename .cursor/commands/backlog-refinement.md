# Backlog Refinement

## Overview

- このコマンドは、ユーザーから与えられた要求仕様をもとにバックログリファインメントを行うワークフローです。
- バックログリファインメントとは、開発タスクを作成する前段階で「どのような成果物が完成とみなされるか」を定義し、**プロダクトバックログアイテム（PBI）**として整理するプロセスです。

## Rules

- PBI は `.github/ISSUE_TEMPLATE/PBI_TEMPLATE.md` を使用して作成し、**Markdown 形式**で出力すること。
- 出力先ディレクトリは `flow/{今日の日付}/` とし、存在しない場合は新規作成すること。
  - **今日の日付**: `date +%Y%m%d` コマンドの出力値を使用する。
- PBI ファイルの命名規則は `{連番}_{PBIタイトル}.md` とする。
  - **連番**: 同一フォルダ内で重複しない連続番号を採番すること。

## Steps

1. ユーザーから要求仕様をユーザーストーリー形式で受け取る。受け取りが完了してから、次のステップに進む。
2. 受け取った情報をもとに、PBI の内容を定義する（**Rules** に従う）。
3. 定義した PBI を Markdown ファイルとして出力する（**Rules** の出力規則を適用する）。
