# PRを作成

## 概要

適切なタイトル、説明のPRを作成する。
PRテンプレート（`.github/pull_request_template.md`）を使用する。
次の手順に従って作業を進め、不明点があればユーザーへ質問する。
作業後にチェックリストを参照し、すべての項目が完了していることを確認する。

## 手順

### 1. 前提確認
- developブランチから派生した作業用ブランチで作業していることを確認する
- すべての変更がコミットされ、プッシュされていることを確認する
- PRテンプレートの内容を確認する

### 2. PRのタイトルを考える
- タイトルにIssue番号と概要を含める
- 例: `feat: フロントエンドにEntraIDログイン機能を実装 (#3)`

### 3. PRの説明を考える
- 変更を明確に要約する
- 背景と動機を含める
- 重大な変更点をリストアップする

### 4. PRを作成・設定する
- 適切なタイトル、説明文でPRを作成する
- **Issue を自動で閉じるために、本文に `Closes #{issue番号}`を記載する**
- 適切なAssigneeを設定する

## チェックリスト

### 前提
- [ ] developブランチから派生した作業ブランチで作業している
- [ ] すべての変更がコミット済みである
- [ ] 作業ブランチの変更をリモートへpush済みである

### PR作成
- [ ] タイトルが規約（`type: 概要 (#番号)`）に従っている
- [ ] 本文に `- Closes #{issue番号}` を記載している
- [ ] 適切なAssigneeを設定している
