# Create PR

## Overview

- このコマンドは、GitHub で Pull Request を作成するワークフローです。
- PR テンプレートを使用し、適切なタイトル・説明・チェック項目を記載して PR を作成します。

## Rules

- PR 作成時の基本ルール（`.cursor/rules/pr-rules.mdc`）を確認する。
- **マージ先ブランチ**:特に指定がない場合は以下のルールでマージ先ブランチを決定する。
  - main から派生したブランチの場合: `main`
  - develop か派生したブランチの場合: `develop`
- 指示がない限り Draft で PR を作成し、PR タイトルの先頭に「[WIP]」を入れる。
- 作業後にチェックリストを参照し、すべての項目が完了していることを確認する。

## Steps

### 1. Issue 番号の確認

- 1. ユーザーから Issue 番号を受け取る。受け取りが完了してから、次のステップに進む。

### 2. マージ先ブランチの確認

- ユーザーにマージ先ブランチを確認する。

### 3. 差分の確認

マージ先ブランチとの差分を確認：

```bash
git diff origin/{{マージ先ブランチ}}...HEAD | cat
```

### 4. 前提条件の確認

- 作業用ブランチで作業していることを確認
- すべての変更がコミット済みであることを確認
- 作業ブランチの変更をリモートへ push 済みであることを確認

### 5. PR テンプレートの確認

- `.cursor/rules/pr-rules.mdc`に記載の PR テンプレートを確認し、記入すべき項目を把握する。

### 6. PR のタイトルを作成

- `.cursor/rules/pr-rules.mdc`に記載の命名規則に従って作成する。

### 7. PR の本文を作成

- PR テンプレートに従って記入する。

### 8. PR を作成する

以下のコマンドで PR を作成し、ブラウザで開く：

```bash
git push origin HEAD && \
echo -e "{{PRテンプレートを1行に変換}}" | \
gh pr create --draft --title "{{PRタイトル}}" --body-file - && \
gh pr view --web
```

> **Note**: `{{PRテンプレートを1行に変換}}` は PR テンプレートの内容を `\n` で改行表現した 1 行の文字列に変換したもの。
