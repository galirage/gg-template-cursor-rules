# Task Breakdown

## Overview

- このコマンドは、**ユーザーから入力された PBI（プロダクトバックログアイテム）の情報をもとにタスクを分解する**ワークフローです。
- 各タスクは、PBI を完了させるために必要な具体的な作業単位を明確化します。

## Rules

- タスクは `.github/ISSUE_TEMPLATE/TASK_TEMPLATE.md` を使用して作成し、**Markdown 形式**で出力すること。
- 出力先ディレクトリは `flow/{今日の日付}/{PBIタイトル}/` とし、存在しない場合は新規作成すること。

  - **今日の日付**: `date +%Y%m%d` コマンドの出力値を使用する。

- タスクファイルの命名規則は `{連番}_{タスクタイトル}.md` とする。

  - **連番**: 実施順に沿って連続番号を採番すること。

- PBI にドキュメント作成が含まれる場合は、**最初のタスクとして「ドキュメントの構成設計」を作成すること。**

## Steps

1. ユーザーから「タイトル」「ユーザーストーリー」「受け入れ条件」を受け取る。
2. 受け取った情報をもとに、PBI を完了させるために必要なタスクを洗い出す。
3. 各タスクをテンプレート（**Rules** 記載の `.github/ISSUE_TEMPLATE/TASK_TEMPLATE.md`）に従って詳細化する。
4. タスクを Markdown ファイルとして出力する（**Rules** の出力ルールを適用する）。
