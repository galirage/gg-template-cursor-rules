# Task Breakdown

## Overview

- ユーザーから入力される PBI（プロダクトバックログアイテム）の情報を元に、タスク分解を行うワークフローです。

## Rules

- タスクは`.github/ISSUE_TEMPLATE/TASK_TEMPLATE.md`テンプレートを使用し、マークダウン形式で出力する。
- タスクファイルの出力先は、`flow/{今日の日付}/{PBIのタイトル}`フォルダを作成し、格納する。
  - **今日の日付**: `date +%Y%m%d` を実行して取得した日付を挿入する
- タスクファイルの命名ルールは`{番号}_{タスクタイトル}.md`とする。
  - **番号**: タスクを実施する順にイシューを連番に並べた際の順番を挿入する
- ドキュメント作成が必要な PBI の場合は、初めのタスクとして「ドキュメントの構成設計」のタスクを作成する。

## Steps

- ユーザーから「タイトル」「ユーザーストーリー」「受け入れ条件」を受け取る。
- ユーザーからの入力情報を元に、PBI を完了させるに必要なタスクを洗い出す。
- タスクの詳細化を行う（## Rules 記載のタスクテンプレートを参照する）。
- タスクをマークダウンファイルとして出力する（出力先は ## Rules 記載内容を確認する）。
