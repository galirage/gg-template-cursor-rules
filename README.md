# Cursor Rules テンプレート

Galirage における **AI 駆動開発の標準基盤** として提供する **Cursor Rules テンプレート** リポジトリです。

## 概要

CTO 室は、全エンジニアが効率的に AI 駆動開発を行えるよう、統一された Cursor Rules テンプレートを提供します。

本テンプレートを活用することで、以下を実現できます：

- **継続的な AI コンテキストの定義**: 設計方針・コーディングスタイル・開発手順等を AI に継続的に伝達
- **プロジェクト固有の知識と方針の統一**: チーム全体での標準化とコミュニケーション円滑化
- **一貫したコード生成**: AI エージェントによる品質の高いコード生成・提案

> ⚠️ **注意**  
> Cursor Version: 1.6.45 を使用しています。  
> 本ドキュメントは作成日（2025/09/18）時点の内容です。最新情報と異なる場合があります。

## Cursor Rules とは

Cursor Rules は、プロジェクト内でルールを記述するためのファイル (`.mdc`) であり、**AI エージェント** と **コード補完** に適用されます。

適用時、その内容は AI へのコンテキストの冒頭に読み込まれ、継続的に AI の動作を制御します。

## 使用方法

### 1. テンプレートの導入

1. 本リポジトリを参照し、`.cursor/rules` ディレクトリ内のルールテンプレートを確認
2. 自身のプロジェクトに `.cursor/rules` ディレクトリを作成
3. 必要なルールファイル（`.mdc`）をプロジェクトにコピー
4. プロジェクトの要件に合わせてルールを調整

### 2. ルールの種類と適用方法

本テンプレートでは **Project Rules** 方式を採用しています：

- **Always Apply**（常に適用）: 基本的なコーディングスタイル、プロジェクト全体のポリシー
- **Apply Intelligently**（関連時に自動適用）: エージェントが指示に関連すると判断した場合に適用
- **Apply to Specific Files**（特定ファイルに適用）: 指定したパターンに一致するファイルにのみ適用
- **Apply Manually**（手動適用）: @メンションされた場合にのみ適用

### 3. ルール更新方法

1. **新規作成**: `/Generate Cursor Rules` コマンドで新規 Rules を生成
2. **編集**: `.mdc` ファイルを直接編集（追加・修正・削除）
   - ファイル命名規則: **snake-case**（例: `architecture-rules.mdc`）
   - 各ファイルに適用範囲・適用条件を明記
   - ルールは **500 行未満** を目安に、肥大化した場合は分割

### 4. テスト方法

ルールの変更・追加後は以下を確認してください：

- **最低限チャット及びコード補完を 1 回実行**
- **出力がルールの意図に沿っているか確認**

## 運用方針

- **チーム単位での運用** を前提とします
- プロジェクトの状況や要件に合わせて **継続的に見直し・更新** を実施
- **最適化の例**:
  - 採用するフレームワークやライブラリ専用 Rules の追加
  - 業務ドメイン（金融、医療など）に特化した Rules の追加
  - クラウド環境別（AWS、GCP）の設定・デプロイ戦略 Rules の追加

## 注意事項

- 本テンプレートは **Project Rules** 方式を使用しています
- 他の Rules 定義方法（User Rules、AGENTS.md、.cursorrules）との併用時は優先順位にご注意ください
- ルールの内容は具体例を記述し、曖昧な表現は避けてください
