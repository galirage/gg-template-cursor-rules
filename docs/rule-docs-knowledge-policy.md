# Cursor Rules と docs ディレクトリと knowledge ディレクトリの棲み分け方針

## Overview

本ドキュメントは、**AI 支援開発環境（Cursor 等）で利用するルールファイル**と、
人間が参照・判断・共有する**チームメンバーが参照する人間向けドキュメント**、**開発知識・ノウハウの共有**の役割を明確にし、
重複・齟齬のないドキュメント運用を実現するための方針を定義します。

---

## 各ディレクトリの位置づけ

### 1. Cursor Rules（`.cursor/rules/`）

- AI が守るべき規約・手順を機械可読形式で定義するルール群。
- コード生成や補助作業における曖昧さを排除し、AI が常に正確な出力を行えるよう設計します。

### 2. docs ディレクトリ（`docs/`）

- チームメンバーが理解・判断・共有するための運用ドキュメントを管理。
- AI への指示ではなく、背景・目的・判断基準を含めた「人間のための説明」を重視します。

### 3. knowledge ディレクトリ（`knowledge/`）

- 開発知識・ノウハウ・ベストプラクティスを蓄積・共有するナレッジベース。
- 正式なルールに至らない段階の知見や Tips、ツール活用法などを整理します。

---

## 棲み分けルール

| 項目           | Cursor Rules（AI 向け）                   | docs（人間向け）                                 | knowledge（知識・ノウハウ）          |
| -------------- | ----------------------------------------- | ------------------------------------------------ | ------------------------------------ |
| 主な目的       | AI が正確な出力を行うための**具体的指示** | メンバー間で共通認識を形成するための**運用方針** | 開発に役立つ**知識・ノウハウの蓄積** |
| 対象           | AI エージェント（Cursor 等）              | 開発チーム全体                                   | 開発チーム全体                       |
| 記述形式       | 一義的・明示的・条件中心                  | 自然言語・背景説明を含む                         | 自然言語・Tips・手法解説中心         |
| 内容の粒度     | コード / 実行単位                         | プロセス / チーム単位                            | 手法 / ツール単位                    |
| 更新タイミング | プロジェクト設定変更時                    | 運用・方針変更時                                 | 新たな知見・ツール導入時             |
| 管理責任       | テックリード / AI 運用担当                | チーム全体 / PM / リードエンジニア               | チーム全体 / 分野担当者              |

---

## 運用ルール

1. **3 つのディレクトリの役割を明確に分離する**

   - Cursor Rules：AI が「実行」すべき命令
   - docs：人間が「理解・判断」するための方針
   - knowledge：開発を支える「知識・ノウハウ」

2. **プロジェクト固有の設定は Project Rules に統合**

   - 例：ディレクトリ構成、テスト方針、フレームワーク指定、エディタ設定など。

3. **docs に記載された運用ルールは、必要に応じて Cursor Rules に昇格**

   - 人間向け規約を AI 向け指示に変換し、トレーサビリティを確保する。

4. **knowledge の知見は、必要に応じて docs または Cursor Rules に昇格**

   - チームで有効性が確認された手法や知識は、正式なルールとして文書化する。

5. **AI と人間の責務を明確に分離する**

   - AI は「生成・補助」、人は「意図確認・判断・決定」を担う。
