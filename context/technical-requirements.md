# 技術要件（Technical Requirements）

> **目的**: Cursor AI 上でバックログリファインメントやタスク分解を行う際に活用します。

## 技術方針（概要レベル）

例：

- **フレームワーク**：Next.js（TypeScript）
- **ホスティング / インフラ**：Vercel, Firebase
- **データベース / 認証**：**Firebase（Firestore + Auth）を使用予定**
- **テスト / ツール**：Vitest, Bun, ESLint, Prettier
- **AI 連携**：OpenAI API または内部プロンプトエンジンを想定

## システムアーキテクチャ方針

_※ 要件整理フェーズで明確化されたシステムアーキテクチャの方針があれば記載_

例：

- **アーキテクチャパターン**：クライアントサーバー型
- **データフロー**：リアルタイム同期を必要とする箇所あり
- **状態管理**：グローバル状態管理の必要性を検討

## データ管理方針

_※ 要件整理フェーズで明確化されたデータ管理方針があれば記載_

例：

- **データ永続化**：ローカルストレージとクラウドの両方を使用
- **同期方式**：リアルタイム同期が必要な機能あり
- **キャッシュ戦略**：オフライン対応を考慮

## その他 AI が理解すべき開発コンテキスト

例：

- バックエンドは Firebase を前提とする。
- React は**関数コンポーネント + Hooks 構成**を採用。
- スタイリングは**Tailwind CSS ユーティリティクラス**を基本とする。
- ドキュメントやテンプレート生成時は、`/docs/` および `/rules/` の構成・命名規則に従う。
